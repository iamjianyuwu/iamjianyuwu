#### How I work

- LLM plus deterministic logic, layered: the model explains, the code computes. Odds, MDF and SPR in AskGTO are never left to the model.
- Eval-gated releases. A change ships when the eval suite passes, not when it feels right.
- Agent-native workflow. Most of my daily tooling is Claude Code and Codex driving small, well-scoped repos with an `AGENTS.md` in each.
- Everything is a written record: hypothesis, action, data, conclusion. Failed experiments stay in the log.
