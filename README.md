#### How I work

- **LLM and deterministic logic, in layers.** The model explains; the code computes. Anything with a right answer is never left to the model.
- **Eval-gated releases.** A change ships when the eval suite passes, not when it feels right.
- **Agent-native workflow.** Claude Code and Codex do most of my daily work, each driving a small, well-scoped repo with its own `AGENTS.md`.
- **A written record for everything.** Hypothesis, action, data, conclusion. Sampling data, funnel numbers and rejections are all made public.
